# JobNest - Smart Job Discovery and Career Platform

JobNest is a modern, responsive front-end job discovery platform built using HTML5, CSS3, and JavaScript. It includes job browsing, filters, saved jobs, application tracking, profile management, category pages, and authentication flows using localStorage for demo purposes.

## Project Features

- Home page with hero section and job search
- Browse and filter jobs dynamically
- View detailed job descriptions
- Save/unsave jobs using LocalStorage
- Apply for jobs with a validation-based form
- View saved jobs and applied jobs
- Manage a simple user profile
- Browse categories and navigate to filtered results
- Login and registration pages with LocalStorage demo authentication
- Responsive design for desktop, tablet, and mobile devices

## Run Locally

Open the project folder in VS Code and launch a local static server, for example:

```bash
cd "c:\Users\shiwani kumari\OneDrive\Desktop\WEB JOB DISCOVERY WEBSITES"
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/index.html
```

## Notes

This is a front-end demonstration project only. Authentication is implemented using localStorage for learning and project demo purposes, not as a secure real-world login system.
